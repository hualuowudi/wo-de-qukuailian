# 拾珠绣 · 区块链溯源系统

非遗珠绣文创品牌「拾珠绣 PEARL VISION」的区块链溯源系统。

消费者扫码 → 输入防伪码 → 查看商品全程溯源海报（制作 → 质检 → 购买），支持链上哈希存证与真伪核验。

## 功能

- **查询页**（CXY.html）：客户输入防伪码，跳转对应溯源海报
- **溯源海报**（index.html）：竖版长图，展示流转环节 + 区块链存证 + 核验真伪
- **后台演示台**（admin.html）：查看数据、生成统一查询二维码、导入表格
- **一件一码**：每件商品独立防伪码 `ZXS-日期-流水号` + 独立哈希链
- **隐私保护**：购买人电话只显示尾号后 4 位、时间模糊、称呼统一

## 快速开始

```bash
# 双击 anzhuang.bat（自动检测/安装 Node.js）
# 然后双击 start.bat 启动本地服务
# 后台：http://127.0.0.1:8080/admin.html
# 查询页：http://127.0.0.1:8080/CXY.html
```

## 目录结构

```
├── CXY.html          客户查询页
├── index.html        溯源海报
├── admin.html        后台演示台
├── list.html         商品列表页
├── server.js         本地静态服务器 + 导入接口
├── anzhuang.bat      Node 自动安装器
├── start.bat         一键启动
├── lib/              共享逻辑（SHA-256 区块链 + SheetJS + 二维码）
├── assets/           商品图 / IP 图
├── data/             溯源数据 JSON + 表格模板 + 购买人信息表
└── tools/            重新上链 / 批量生成脚本
```
