本地演示：查看溯源数据 / 哈希链 / 生成扫码二维码

导入商品信息（表格 → 一键生成溯源数据）

上传一张包含商品与购买人信息的 Excel 表格，系统自动识别并生成每件商品的溯源数据 + 重新上链。商品图（包包图）为固定素材，无需每次导入。
表格需包含列：防伪码、商品名称、价格、绣娘、质检员、制作时间、质检时间、购买人名称、购买人电话、购买时间。可 下载模板。

溯源数据（商品 + 流转环节）

购买人信息读取自 data/购买人信息表.xlsx（信息表传递，不连接进销存系统）。

区块链存证（4 个区块 · 链式哈希）

客户查询二维码（统一贴包装）

统一查询码
客户扫码 → 输入防伪码 → 看海报
这是贴在所有商品包装上的统一二维码，客户扫码进入查询页，输入对应防伪码即可查看该商品的溯源海报。
手机扫码前，请先填对下方「服务器地址」：手机和电脑连同一 WiFi，地址要填电脑的局域网 IP（不是 127.0.0.1）。
正式上线后，这里会替换成公网地址。

演示脚本（照着走一遍）

  1. 手机连同一 WiFi，微信扫上方「统一查询码」→ 进入查询页。
  2. 在查询页输入某个防伪码（如 ZXS-20261116-0001）→ 点「查询」→ 展示该商品溯源海报，点「核验真伪」显示 ✓ 正品。
  3. 回到本页，可切换上方商品查看不同商品的哈希链。
  4. 要新增/更新商品：更新 Excel 表格 → 本页「导入并生成」→ 数据自动更新并重新上链。
