拾珠绣 · 区块链溯源系统 —— 使用说明
============================================

【这是什么】
一套用于「演示 / 轻量上线」的珠绣文创区块链溯源系统。
客户扫统一二维码 → 进入查询页 → 输入防伪码 → 看到该商品全程溯源 + 链上存证。
每件商品一件一码，防伪码全网唯一。

【核心工作流（你日常只需两步）】
1. 更新 Excel 表格（一张表：商品信息 + 购买人信息 + 防伪码）
2. 后台「选择文件 → 导入并生成」→ 系统自动生成溯源数据 + 重新上链

【怎么启动（自己就能跑）】
1. 双击本文件夹里的 start.bat（需已安装 Node.js）
2. 黑色窗口保持开着，别关
3. 浏览器打开 http://127.0.0.1:8080/admin.html —— 这是「后台」（导入数据、生成二维码）
4. 浏览器打开 http://127.0.0.1:8080/CXY.html —— 这是「客户查询页」（输入防伪码看海报）

【导入表格怎么用】
1. 下载模板：后台页面的「下载模板」链接，或 data/溯源模板.xlsx
2. 模板列：防伪码、商品名称、价格、绣娘、质检员、制作时间、质检时间、购买人名称、购买人电话、购买时间
3. 在模板里填 / 改数据（防伪码自己填，如 ZXS-20261116-0001）
4. 后台「选择文件」选这张表 → 点「导入并生成」→ 提示成功后自动刷新
5. 商品图（包包图）为固定素材，不用每次导入

【客户怎么用（扫码 → 输码 → 看海报）】
1. 客户扫包装上的统一二维码 → 进入查询页 CXY
2. 输入商品上的防伪码 → 点「查询」
3. 命中 → 显示该商品溯源海报（点「核验真伪」看链上存证）
4. 输错 / 假码 → 提示「防伪码不存在，谨防假冒」

【文件结构】
  CXY.html             客户查询页（输防伪码 → 看海报）
  index.html           溯源海报（?code= 参数）
  admin.html           后台（导入数据 / 生成统一二维码 / 看哈希链）
  list.html            商品列表页（可选）
  server.js            服务器（含 /api/import 导入接口）
  start.bat            一键启动
  lib/app.js           共享逻辑：SHA-256 + 区块链
  lib/xlsx.full.min.js 解析 Excel
  lib/qrcode.min.js    生成二维码
  assets/              商品图 product.png、IP 头图 ip.png
  data/溯源数据.json    溯源数据（导入后自动生成）
  data/溯源模板.xlsx    表格模板
  data/购买人信息表.xlsx 旧购买人表（可选）

【注意】
- 必须通过 start.bat 启动访问（http:// 开头），不要直接双击 HTML 打开
- 端口默认 8080，被占用时用环境变量 PORT 换端口
- 当前是本地/局域网运行：客户需和电脑连同一 WiFi 才能扫码访问；
  要正式上线（任意客户随时扫），需部署到公网，部署方式另行确定
- 导入会覆盖现有溯源数据并重新上链，请确认表格无误后再导入
